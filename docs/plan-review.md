# Adversarial plan review — 2026-11-01

Structured self-review before implementation. This records design findings and adopted remedies, not passing implementation claims.

| Lens            | Severity / finding                                                 | Plan change / verification                                                                                                                                                                        |
| --------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Simplifier      | Major: duplicated guest UI would become a second app               | Reuse existing plant DTO/UI via a narrow local adapter; reuse shared profile/camera and existing navigation. Test old signed-in flows.                                                            |
| Child           | Major: separate game screen hides first quest                      | Home preview and one labeled rewards entry; first bundled discovery quest is offline-achievable. Measure path.                                                                                    |
| Grandparent     | Major: annual/seasonal and daily watering are misleading           | Separate lifespan; plain explanations; care means check, not water. Large wrapping text.                                                                                                          |
| Mission skeptic | Major: reward on renders/search suggestions invites farming        | Persist action receipts, species/category unique keys and daily planting/care limits; replay/alias/delete tests.                                                                                  |
| Accessibility   | Major: swipe-only deletion and five-second undo exclude people     | Visible overflow menu, accessibility action, screen-reader nonexpiring undo, opaque high-contrast surfaces. Test with platform settings.                                                          |
| Privacy         | Blocker: entire app currently needs Clerk                          | Explicit guest namespace/local adapter; no fake token, no automatic migration, no public private routes. Guest/cloud separation tests.                                                            |
| Safety          | Major: classifier confidence mistaken for ecological certainty     | Positive/negative only with ecology evidence, uncertainty otherwise; possible-sting warning; no abundance guesses.                                                                                |
| Failure hunter  | Blocker: current DELETE immediately cascades                       | Persisted pre-dispatch undo journal; retain original until final acknowledgement; restart/account-switch tests.                                                                                   |
| Failure hunter  | Major: migrations overwrite schema version                         | Version-gated additive storage; old draft mode defaults plant; migration tests.                                                                                                                   |
| Provider review | Blocker: a free-form model or fake is not a live insect classifier | Separate strict classifier port/config. Leave live enablement blocked without credentials, retention approval and hard quota. Independent local work can proceed; no claim of F3 live completion. |

All design blockers have a concrete plan remedy. Implementation still must prove these remedies. External provider/privacy/device acceptance is not resolved by this document and must remain visible in implementation review.
